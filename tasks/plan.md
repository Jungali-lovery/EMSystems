### Lệnh khôi phục vật lý

1. Dừng business API và payment service.
2. Chạy npm run backup:data trước nếu cần giữ trạng thái hiện tại.
3. Chạy npm run restore:data -- ".emsystems-backups/<tên-bản-backup>" --confirm.
4. Chỉ khởi động dịch vụ khi script báo Restore completed; giữ bản .pre-restore-...bak cho rollback.
